INSTALL:
1. Extract this ZIP.
2. Copy the included `pages` folder into the root of your existing Saniya website folder, beside index.html, styles.css and script.js.
3. Each page has its own styling and uses the requested colors: black, maroon (#800000), and pink (#FFC0CB).
4. Each page links back to ../index.html.

Your project cards in index.html will need links pointing to these filenames if those links are not already added.
