# Saniya Ansari — Personal Portfolio

A fresh, original, single-page responsive portfolio for Saniya Ansari. It is built with plain HTML, CSS and JavaScript and does not reuse the Peach Portfolio template's source code, photographs, illustrations or branding. The supplied ZIP was used only as a reference for the kind of polished, animated portfolio experience requested.

## Features

- Responsive layout for desktop, tablet and mobile
- Friendly cursor-tracking eyes with blinking and hover reactions; gentle idle movement on touch devices
- Recruiter and freelance-client paths on the homepage
- About, grouped skills, experience timeline, project cards, certifications, education, hobbies and contact sections
- Studio Chrom featured freelance project with a case-study dialog and live website link
- Light/dark theme toggle (preference saved in browser local storage)
- Scroll reveal animations and reading progress indicator
- Downloadable resume PDF
- No build tools or dependencies required

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. For example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing

1. Replace the generic LinkedIn and GitHub URLs in `index.html` with your personal profile URLs.
2. Add public GitHub/demo links to projects when available. No project repository URLs were provided, so none have been invented.
3. Add project screenshots and the actual six certificate images if you want visual evidence in those sections.
4. Confirm that the resume PDF is the latest version before publishing.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive design, light/dark themes and animations
- `script.js` — eye tracking, menu, theme, scroll reveals and project dialogs
- `assets/Saniya-Ansari-Resume.pdf` — supplied resume
